## P0 缺陷（已修复）

dogfood 暴露的两个批准可靠性缺陷已在 v0.2 范围冻结前修复：

- **Engine fingerprint 绑定 Python 运行时**：审核端与起草端解释器不同即触发 `EngineChanged`，全部 validation 失效，批准静默失败。已按 ADR-014 移除 Python 运行时，指纹只含 Beancount 与 ledger-kernel 版本。
- **空 `write_target` 首笔提交使批量批准失效**：首笔提交后追加分隔符从无到有，其余草稿 `review_digest` 变化，`ApprovalCarriedForward` 不生效。已按 ADR-015 改为哈希交易正文，空账本批量批准一次完成。

两项都有回归测试；修复前的 69.5 秒中位数值保留在本节上方作为历史基线，修复后的同规模复测待下一轮 dogfood。
