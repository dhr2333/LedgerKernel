## 阅读顺序

1. 先读顶层设计摘要，确认“内核是自动化写入的唯一受控入口，用户保留最高编辑权”。
2. 再读实施计划，确认 v0.1 的冻结边界与验收项。
3. 需要实现细节时读设计规格；涉及增量断言/批准沿用再看 ADR。
4. 当前代码行为与文档冲突时，以仓库 `README.md`、代码测试和最新 ADR 为准；发现不一致请提交 issue/PR。

## 文档状态

这些文档描述的是 **v0.1 原型基线**，不是长期产品承诺。标记为 `[建议冻结]` 的事项已经在该原型中实现，但后续版本仍可能通过新 ADR 修订。安全边界与已知限制以仓库 README 为准。
